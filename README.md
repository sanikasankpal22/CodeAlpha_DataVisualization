# CodeAlpha - Sales Performance Dashboard

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The project focuses on data visualization and sales performance analysis using Microsoft Power BI. An interactive dashboard was created to analyze sales, profit, discount, quantity, shipping cost, products, categories, and regional performance.

## Objectives

- Analyze overall sales performance
- Compare sales and profit across different regions
- Analyze sales by product and category
- Examine discount trends over the years
- Compare average sales across regions
- Analyze average profit by region
- Provide interactive filtering for better data exploration

## Tool Used

- Microsoft Power BI
- Power Query
- Data Visualization

## Dashboard Features

The dashboard includes the following:

- Total Sales
- Total Profit
- Total Discount
- Total Quantity
- Total Shipping Cost
- Sales by Product
- Discount by Year
- Average Sales by Region
- Average Profit by Region
- Average Sales by Category
- Category filter
- Ship Mode filter

## Dashboard KPIs

The dashboard displays the following overall metrics:

- **Total Sales:** 10M
- **Total Profit:** 1.14M
- **Total Discount:** 3K
- **Total Quantity:** 125K
- **Total Shipping Cost:** 1.07M

## Key Insights

- The dashboard provides an overview of overall sales and profitability.
- Sales performance can be compared across different products and regions.
- Technology has the highest average sales among the displayed categories.
- The discount trend shows a decreasing pattern from 2011 to 2014.
- Regional charts allow comparison of average sales and average profit across different regions.
- Interactive filters allow users to analyze specific product categories and shipping modes.

## Dashboard Preview

The dashboard contains interactive visualizations for sales, profit, discount, quantity, shipping cost, product performance, category performance, and regional analysis.
